# Loom docs — `loom/docs/`

Loom is the **builder/manager** product — scaffolding, agentic workflows, and lifecycle management for delivery-ops apps. Its docs live here, owned by Loom per **D44**, distinct from `lighthouse/docs/` (Lighthouse product docs) and `docs/` (cross-app hub for shared architecture, API contracts, and guides).

## Layout

| Path | What lives there |
|------|-----------------|
| `loom/docs/README.md` | This file — product docs home |
| `loom/docs/guides/` | Loom user and developer guides |
| `loom/docs/technical/` | Loom architecture, decisions, and design docs |
| `loom/docs/api/` | Loom API and MCP tool contracts |
| `loom/docs/runbooks/` | Loom operational runbooks |
