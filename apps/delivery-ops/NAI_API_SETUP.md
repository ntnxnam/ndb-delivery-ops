# NAI API Key Setup Guide

## How to Use Your NAI API Key

You now have the **Generate Executive Report** button in the Release Trends page. Here's how to set it up:

### Step 1: Access the Release Trends Page
1. Navigate to Release Trends page in your application
2. Select a release version (e.g., NDB-2.11)
3. Click "Refresh Summary" to load the executive summary data

### Step 2: Set Up NAI API Key
1. Click the **"🎯 Generate Executive Report"** button
2. A modal will appear asking for your NAI API key
3. Enter your NAI API key: **xxxxxxxxxxxxxxxxxx**
4. Click **"Test & Save"** to validate and store the key

### Step 3: Generate VP Reports
- Once the key is validated and saved, you can generate AI-powered VP reports anytime
- The key is stored securely in your browser's localStorage
- If the key expires, you'll be prompted to update it

## Security Notes

- **Your API key is stored locally** in your browser only
- **Never share your API key** with others
- **The key is sent directly to NAI** - it doesn't go through our server
- **You can clear the key** anytime using the "Clear Stored Key" button

## Troubleshooting

- **"API key expired"**: Click the Generate button again to update your key
- **"Rate limit exceeded"**: Wait a few minutes before trying again
- **Network issues**: Check your internet connection

## Support
