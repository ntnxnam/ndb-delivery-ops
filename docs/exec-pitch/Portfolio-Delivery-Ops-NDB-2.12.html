02 · Elevator — 30 sec

70% of a Portfolio Manager’s week is reactive. Delivery Ops makes it self-service.

Loom — personal dev manager

  • I describe the problem; Loom reasons and locks a Goal Contract
  • Weave orchestrates leads → workers with prescribed model/thinking/context
  • KPI-gated, audit-trailed; notifies me when done

Lighthouse — portfolio view

  • Project plan, feature dashboards, KPIs, exec briefings — live from JIRA
  • Repeat-activity lenses: On-call, CFD/CFI, System Test
  • Bulk + project email, all citation-backed

Why now

TPMs chase deterministic repeat work (same JQL, same follow-ups) we don’t need humans for. I’m automating that with a TPM agent — so my time buys product insight, customer impact, and what the data says about the team.

07 · How we build vs how we run

Loom builds it. Lighthouse lights it.

  • Delegates to Weave: per-lead model/thinking/context/KPIs
