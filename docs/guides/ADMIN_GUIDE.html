# Admin Guide

> For architects / admins. Maintained by `doc-specialist` via `doc-admin-guide`.

## Prerequisites

- Node 20+, PM2, Nginx
- JIRA PAT (Bearer per D40) — `JIRA_PAT` env

## Installation

```bash
./scripts/start.sh   # backend 8001, frontend 8899
./scripts/stop.sh
```

## Teams Config — filter/project + people/roles + sprint/board

> Canonical: `docs/pages/Admin-requirements.md` + `Admin-data-layer.md` · API: `docs/api/admin.md#post-apiteams` · Code: `shared/src/services/teamBaseJqlService.ts` (SoT `SHARED_PROJECTS_ALL`=10), `apps/delivery-ops/server/services/teamAdminService.js` (`buildBaseJqlFromTeam`), `apps/delivery-ops/client/src/components/AdminPanel/TeamForm.js` (`buildPreview`/`formatJql`), `server/utils/sprintCalendar.js` (`inferSprintCalendarFromSprints` recent-10, `snapSprintDays`).

### Filter / project shape

| Mode | JQL generated |
|------|---------------|
| **Shared Project** (`is_shared_project: true`, `custom_project_key: null`) | `project in (ENG, FEAT, ONCALL, TH, SDL, TECHPUBS, SR, LEG, ACP, LBDR) AND (component in (…) OR "primary component" in (…) OR assignee in (…) OR issuetype in ("Era Oncall","ERA Oncall"))` |
| **Not Shared / Custom** (`is_shared_project: false`, `custom_project_key: "ERA,NDBECO"`) | `(project in (ERA, NDBECO) OR (project in (ENG, FEAT, ONCALL, TH, SDL, TECHPUBS, SR, LEG, ACP, LBDR) AND (component in (…) OR "primary component" in (…) OR assignee in (…) OR issuetype in ("Era Oncall","ERA Oncall"))))` |

- 10 shared = `ENG` + 9 horizontals `FEAT,ONCALL,TH,SDL,TECHPUBS,SR,LEG,ACP,LBDR` (`shared/src/services/teamBaseJqlService.ts:SHARED_PROJECTS_ALL`, `LEGACY=[]`). NDB private is `ERA,NDBECO` per 2026-11-24 sample; other teams comma-separate their private keys.
- Components are required (≥1) — validated against `GET /rest/api/2/project/{key}/components` for ENG + each horizontal; suggestions in `TeamForm.js:KNOWN_COMPONENTS` (Atlas).
- `base_jql` + `baseFilter` both persisted for compat; `sprintScope` derived via `sprintScopeFromBaseFilter` (strip `ORDER BY` + trailing `statusCategory != Done`) is never stored.

### People / assignee inner OR

```
assignee in (
  membersOf("PM-DL") OR membersOf("Dev-DL") OR membersOf("QA-DL")  ← leader_outlook_dls[3]
  OR membersOf("contact DLs")                                      ← 8 rows where isDL=true
  OR handle1, handle2                                               ← 8 rows where isDL=false
)
```

- **Leadership DLs — PM / Dev / QA (3):** dedicated inputs `pmDL`/`devDL`/`qaDL` → `leader_outlook_dls: string[0..3]` (trimmed, deduped) → auto `membersOf` inner OR; also stored for email distribution. No re-typing in Contacts needed.
- **Role / Function Contacts — 8 rows:** `team`/`serv_team`/`doc_team`/`security_team`/`legal`/`documentation`/`trade_compliance`/`others` each `{entries: string[], isDL: boolean}` → `ChipInput` (Enter/`,`/paste/`blur` add, 24px × remove, `DL` checkbox `→ membersOf` vs `→ handle` label). All rows combined via `dedupeTrim` into single `assignee in (…)` clause inner-ORed with `component` / `"primary component"` / `issuetype` — see `shared/src/services/teamBaseJqlService.ts:buildInnerOr` SoT.
- UX guard: typing a chip without pressing Enter still commits on blur — Save never ignores visible input. Preview updates live; `baseFilterTouched` preserves manual override on edit.

### Sprint / board + calendar (S1 + 21d, recent-10)

| Field | Type | Notes |
|-------|------|-------|
| `boardId` | `number \| null` | Board number from Jira Agility board URL (`/rest/agile/1.0/board/{id}`) — one per team, not per component. InputMode numeric, strip non-digits. |
| `sprintCalendar.s1StartIso` | `YYYY-MM-DD` | S1 start date — prefers sprint named `S1`/`Sprint 1` else earliest dated sprint; manual date input allowed. |
| `sprintCalendar.sprintDays` | `1–90` int, default **21** | Sprint length snapped via `snapSprintDays`: 6–9→7, 13–16→14, 19–22→21 else rounded. Inferred from **recent 10** sprints median (`dated.slice(-10)` when >10) so 15×14d old + 8×21d recent correctly yields 21d. Fallback 21d when no durations. Manual number input 1–90. |

- Collection: `server/utils/sprintCalendar.js:collectSprintCalendarFromBoard` paginates `GET /rest/agile/1.0/board/{id}/sprint` (50/page, max 4 pages) → `inferSprintCalendarFromSprints`. Board load errors return `calendarError` without failing Detect; form shows manual fallback.
- UI: `Sprint Board — for full team` row has **Board #** + **Sprint duration** + **Base date S1** → **Load Calendar** (`POST /api/admin/board-calendar`) → **Auto-detect from project** (`POST /api/admin/project-scope` → best board by `projectKeyOrId`). Success shows `S1 2022-12-06 · 21 days`; missing calendar shows `Could not detect — fill manually`.
- `parseSprintCalendar` validates `ISO_DATE` + 1–90 int; `sprintCalendar` is now optional on Save (auto-detect on first board fetch) but shown as required in form when present.

## AI / NAI Configuration

All AI surfaces (chat, exec summary, release briefing, bin-packing converter) use the NAI (Nutanix Enterprise AI) gateway. Secrets are never stored in config files.

### Environment variables (canonical `NAI_*`)

Five `NAI_*` variables are canonical. No `AI_*` fallback is read — only `NAI_*` env vars (or `aiConfig.json` defaults for non-secrets) are considered.

| Var | Secret? | Required | Default / fallback | Notes |
|---|---|---|---|---|
| `NAI_API_KEY` | yes | Required for any AI call | *(none)* — must be set in `server/.env` | NuToken from `tokens.corp.nutanix.com`. No fallback file. Server error: `NAI_API_KEY is not set. Retrieve the key from tokens.corp.nutanix.com and set it in server/.env.` |
| `NAI_API_BASE_URL` | no | Yes, if overriding | `aiConfig.json:baseUrl` (`https://tokens.corp.nutanix.com/enterpriseai/gateway/v1`) | Env overrides `aiConfig.json` (no `AI_*` fallback). Server error: `NAI_API_BASE_URL is not set…` |
| `NAI_DEFAULT_MODEL` | no | Yes, if overriding | `aiConfig.json:defaultModel` (`beam-1-501b`) | Also accepts legacy `NAI_MODEL`. Server error: `NAI_DEFAULT_MODEL is not set…` |
| `NAI_MAX_TOKENS` | no | Yes, if overriding | `aiConfig.json:maxTokens` (8192) | Env parsed as int (no `AI_*` fallback). Server error: `NAI_MAX_TOKENS is not set…` |
| `NAI_REQUEST_TIMEOUT` | no | Yes, if overriding | `aiConfig.json:requestTimeoutMs` (120000 ms) | Env parsed as int ms (no `AI_*` fallback). Server error: `NAI_REQUEST_TIMEOUT is not set…` |

Full table + rationale in [AI_API_CONFIGURATION.md](./AI_API_CONFIGURATION.md) and [NAI_API_SETUP.md](./NAI_API_SETUP.md).

### Precedence diagram

```
per-call override (aiConnector options)
        │
        ▼
  NAI_* env var (no AI_* fallback)
        │
        ▼
  aiConfig.json  (server/config/aiConfig.json)
  { baseUrl, defaultModel, maxTokens, requestTimeoutMs }
        │
        ▼
  missing → throw actionable error naming the NAI_* var
```

- **Secrets** (`NAI_API_KEY`): env only — never in `aiConfig.json`.
- **Non-secrets** (`NAI_API_BASE_URL`, `NAI_DEFAULT_MODEL`, `NAI_MAX_TOKENS`, `NAI_REQUEST_TIMEOUT`): `NAI_*` env → `aiConfig.json` → throw `NAI_* is not set` (no `AI_*` fallback).
- Implementation: `shared/src/connectors/aiConnector.ts` and `apps/delivery-ops/server/.env.example`.

### Bin-Packing Converter — server / auth

| Concern | Detail |
|---|---|
| Route | `POST /api/bin-packing/convert` → `apps/delivery-ops/server/routes/binPackingConvert.js` (mounted at `/api/bin-packing` in `server/index.js`) |
| Auth | `apiLimiter` + `validateJiraTokenMiddleware` — same guard as `POST /api/ai/chat` and `/api/jira-digging`. Unauthenticated requests receive 401 before any file processing. |
| Input | Accepts both `multipart/form-data` (primary) and `JSON { filename, contentBase64, mimeType, productId }` (alternate). Max file 10 MB (multipart) / ~13 MB b64 (JSON). |
| Body parser | `bodyParser.json({ limit: '15mb' })` in `server/index.js` — raised from 1 MB to accommodate 10 MB binary (≈13.3 MB b64) via the JSON path. `bodyParser.urlencoded` also `15mb`. |
| Temp files | Per-request `mkdtemp` via `shared/src/services/csvConverterService.ts`; never executes from the upload dir (downloaded files are untrusted — see project `AGENTS.md` environment note). |

## Troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| Missing sidebar tab | Permission not mapped | Sync `LEGACY_PERMISSION_MAPPING` both sides, re-test permissions |
| 401 from JIRA | PAT expired | Rotate `JIRA_PAT`, Bearer header |
| `NAI_API_KEY is not set` on AI call | `NAI_API_KEY` missing from `server/.env` | Set `NAI_API_KEY` (NuToken from `tokens.corp.nutanix.com`); see [NAI_API_SETUP.md](./NAI_API_SETUP.md) |
| `NAI_API_BASE_URL is not set` | No `NAI_API_BASE_URL` env and `aiConfig.json` missing/misconfigured | Set `NAI_API_BASE_URL` in env or ensure `server/config/aiConfig.json` has `baseUrl` |
| 401 on `POST /api/bin-packing/convert` | Missing/invalid JIRA Bearer token | Same fix as `POST /api/ai/chat` — supply `Authorization: Bearer <JIRA_PAT>` |
| 401 on `POST /api/ai/oncall-concern` / `oncall-slice` | Missing JIRA token / `kpi_view` | Supply `Authorization: Bearer <PAT>`; check `allowedUsers.json` maps `kpi_view` |
| 413 / 422 on bin-packing upload | File > 10 MB or unsupported type | Reduce file or convert to CSV/XLSX; see [CSV_CONVERTER_GUIDE.md](../product/CSV_CONVERTER_GUIDE.md) |
| TCMS Quality shows "Not Set" | TCMS timeout / no runs in window | Check TCMS reachability; Last 4 weeks shows Not Set when no runs in window (no fallback to Overall). Time-filtered calls use `/api/v1/all_test_cases/aggregate/metrics` (`time_filter=four_weeks`, `target={milestone}-qcow2`). |
| TCMS Functional/System identical | Clone caveat (pending `test_category` filter) | Expected until TCMS ships filter; see `docs/tcms-rows-followup.md` |
