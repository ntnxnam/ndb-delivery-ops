# Project skills

Project-specific skills go here. User-level skills are inherited automatically:

- `~/.cursor/skills/vp-release-report/`
- `~/.cursor/skills/fetch-project-tickets/`
- `~/.cursor/skills/sprint-gantt-chart/`
- `~/.cursor/skills/predictive-vp-analytics/`
- `~/.cursor/skills/confluence-width-cleanup/`

Add a skill here only when it specifically needs the structure of this repo
(e.g. a skill that calls a workspace-local MCP tool by absolute path). See
`~/.cursor/skills/AGENTS.md` for skill authoring rules.
